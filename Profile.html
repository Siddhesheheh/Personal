Steam Discovery Mode

Finding a new game on Steam takes a lot of effort. I researched why, then designed a mode that makes exploring easier.

  1. Researched. Ran a survey and qualitative interviews on game-discovery pain points.
  2. Defined who it's for. Chose "Discovery Seekers" as the target persona.
  3. Designed. Created an intent-based Discovery Mode with four features.
  4. Prioritized and measured. Set success metrics and guardrails, then wrote user flows, edge cases and a PRD.
